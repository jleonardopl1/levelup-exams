# Relatórios semanais do radar de repositórios

Um arquivo por varredura (`AAAA-MM-DD.md`), escrito pela tarefa agendada de toda segunda-feira
seguindo a skill [`radar-repositorios`](../../../.claude/skills/radar-repositorios/SKILL.md).
Cada relatório termina com o pedido de de acordo do dono; nada é instalado sem ele.
