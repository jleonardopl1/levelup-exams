# Template de handoff

Copie para o topo de *Handoff mais recente* em `AGENTS-COLLAB.md`. Fail-closed: o próximo agente
não pode precisar adivinhar nada.

```markdown
### AAAA-MM-DD · <tema> (`<agente>` + `<agente>`)
- **Objetivo da sessão:** <o pedido, em uma frase>
- **O que mudou:** <arquivos/áreas, comportamento novo para o aluno ou para a equipe>
- **Testado:** <comando → resultado real (cole a linha final)>
- **Não testado:** <o que ficou sem verificação e por quê>
- **Decisões tomadas:** <D# novas ou alteradas; registre também em "Decisões ativas">
- **Armadilhas novas:** <registre também em "Armadilhas conhecidas">
- **Bloqueios / pendências:** <o que depende do dono ou de outra faixa>
- **Próximo passo sugerido:** <uma ação concreta, com a faixa responsável>
```
